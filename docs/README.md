## Historical records

Detailed Sprint 0–5 plans and `docs/evidence/sprint-*` are historical implementation records. Their original Buyer, Supplier, Purchase Order, and procurement terminology is intentionally preserved. They must not be rewritten to imply the agricultural-trade direction existed before the post-Sprint-5 pivot.

Living code and technical documents may retain legacy paths and identifiers during Sprint 6. Use the terminology mapping in the pivot authority for current user-facing language.
